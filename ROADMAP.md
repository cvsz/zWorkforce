# Roadmap

## v1.0.0 — implemented
Agent registry; model router; provider adapter; persistent task state; approval/cancel/recovery/idempotency; bounded tools/delegation; usage ledger/budgets; RBAC/audit/dashboard/metrics; Docker/CI/tests/docs.

## v1.1 — distributed execution
PostgreSQL repository adapter, durable lease queue, worker heartbeats, dead-letter/retry envelopes, separate API/worker deployment, OpenTelemetry.

## v1.2 — enterprise identity
OIDC/SAML, SCIM/group mapping, per-tool grants, policy-as-code, four-eyes approvals, immutable external audit sink.

## v1.3 — outcome economics
Evaluators, cost per successful task/business outcome, rightsizing recommendations, chargeback/showback, SLO reporting.

## v2.0
Multi-provider health-aware routing, workspace memory/RAG adapters, signed agent/skill registry, tenant isolation and multi-region scheduling.
