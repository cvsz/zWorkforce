# zider Feature Specifications & Capabilities Matrix (v1.1)

`zider` is a full-featured, enterprise-grade AI browser sidebar and companion built for zWorkforce, inspired by Sider.ai.

---

## 1. Complete Capability Matrix

| Feature Module | Capabilities |
| :--- | :--- |
| **Persistent AI Sidebar** | Closed Shadow DOM isolation (`Ctrl+M` / `Cmd+M` toggle), edge handle, multi-tab layout, light/dark responsiveness. |
| **Multi-Model Orchestration** | OpenAI (GPT-4o, o3-mini), Anthropic (Claude 3.5 Sonnet), Gemini 2.0, DeepSeek (R1, V3), OpenRouter / Spawn Hermes 3 Free. |
| **Group AI Chat** | Compare multiple models in parallel with real-time SSE streaming. |
| **Live Web Search Grounding** | Toggle real-time search queries and grounding citations integrated directly into conversational responses. |
| **Vision & Screen OCR** | 1-click visible tab screen snipping, image upload, OCR text extraction, UI wireframe inspection, and visual Q&A. |
| **ChatPDF & Documents** | Multi-page PDF parsing, semantic chunking, and cited Q&A. |
| **Prompt Template Library** | Categorized 1-click prompt library covering Coding, Writing, Reading, Academic, and Web Automation. |
| **Inline Web Input Helper** | Floating "⚡ AI Write" button on web textareas and inputs (Gmail, X/Twitter, LinkedIn, GitHub, Reddit) to compose, improve, or reply in-place. |
| **Media & Web Summarizer** | YouTube video chapters/timestamp breakdown and clean article body extraction. |
| **In-Place Translation** | Quick selection translator + full page dual-column translation supporting 50+ languages. |
| **Chat History & Export** | Local persistence across browser sessions, 1-click Markdown export, and instant session clearing. |
| **Autonomous Agent Claw** | Multi-step task planning and execution with explicit human-in-the-loop safety boundaries. |
| **Options & Customization** | Extension preferences page (`options.html`) for custom gateway endpoints, default models, and keybindings. |
